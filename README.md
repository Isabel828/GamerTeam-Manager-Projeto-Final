# GamerTeam Manager - Projeto Final

## Como rodar no VS Code
1. Abra esta pasta no VS Code.
2. Abra o terminal do VS Code.
3. Execute: `npm install`
4. Depois execute: `node sistemaDeGames.js`

Menu:
1. Sair
2. Adicionar jogador
3. Deletar jogador
4. Calcular média
5. Atualizar pontos
6. Buscar jogador (Busca Linear - Projeto Final da Aula 11)
